# 🎨 Нормализация Стиля для ТГ Канала

## 🎯 Проблема

Авторы статей часто пишут в личном стиле:
- ❌ "Привет! Меня зовут Иван, и я хочу рассказать..."
- ❌ "Сегодня я решил поделиться своим опытом..."
- ❌ "Давно хотел написать про эту тему..."
- ❌ "В этой статье я расскажу как я..."

**Для ТГ канала это неподходяще!**

---

## ✅ Решение: StyleNormalizerAgent

Новый агент который:
1. **Убирает личные обращения**
   - "Привет, меня зовут..."
   - "В этой статье я..."
   - "Хочу поделиться..."

2. **Делает профессиональный стиль**
   - Нейтральный тон
   - Без первого лица
   - Прямо к делу

3. **Готовит для ТГ канала**
   - Единый стиль
   - Без воды
   - Информативно

---

## 📊 Примеры Работы

### Пример 1: Личное Обращение

**БЫЛО:**
```
Привет! Меня зовут Александр, и я backend-разработчик. 
В этой статье я хочу рассказать про то, как я настроил 
Docker в production. Недавно я столкнулся с проблемой...
```

**СТАЛО:**
```
Docker в production требует тщательной настройки. 
Рассмотрим основные подходы к конфигурации и 
типичные проблемы при развертывании...
```

### Пример 2: "Я" в начале

**БЫЛО:**
```
Я долго искал решение для мониторинга микросервисов. 
Я пробовал Prometheus, Grafana, но мне не подошли. 
Тогда я решил написать свой инструмент...
```

**СТАЛО:**
```
Мониторинг микросервисов - критичная задача. 
Существующие решения (Prometheus, Grafana) не всегда 
покрывают специфичные требования. Разберём альтернативный подход...
```

### Пример 3: История от Первого Лица

**БЫЛО:**
```
Когда я начинал изучать Kubernetes, у меня было много вопросов.
Я не понимал как работают поды, сервисы. Сегодня я поделюсь 
тем, что я узнал за год работы...
```

**СТАЛО:**
```
Kubernetes может показаться сложным на старте. 
Основные концепции: поды, сервисы, развертывания. 
Практический опыт показывает следующие подходы...
```

## ⚙️ Настройка

### Изменить Промпт

Отредактируйте:
```
src/application/ai_services/agents/style_normalizer_agent.py
```

В функции `normalize_intro()` найдите промпт и измените требования.

### Отключить для Конкретных Статей

```python
# Без нормализации стиля
article = orchestrator.process_article(
    article,
    normalize_style=False  # Отключить
)
```

### Настроить Длину для ТГ

```python
# Нормализовать с ограничением длины
normalized = style_normalizer.normalize_full_text(
    content,
    max_length=3000  # Для ТГ поста
)
```

## 📊 Где Сохраняется

| Поле | Что Содержит |
|------|--------------|
| `content` | Оригинальный текст статьи |
| `editorial_rewritten` | Нормализованный текст (начало) |
| `editorial_title` | Улучшенный заголовок |
| `editorial_teaser` | Краткое описание |

### Просмотр в Directus

```
http://localhost:8055
→ Content → articles
→ Кликнуть на статью
→ Поле "Editorial Rewritten"
```

### Через API

```bash
curl http://localhost:8000/api/v1/articles/1 | jq .editorial_rewritten
```

## 🔧 Тонкая Настройка

### Что НЕ Убирать

Если хотите оставить некоторые обращения, измените промпт:

```python
# В style_normalizer_agent.py
prompt = f"""...
УБЕРИ:
- "Привет, меня зовут..."
- "В этой статье я расскажу..."

НО ОСТАВЬ:
- Технические термины
- Примеры кода
- Конкретные факты
..."""
```

### Разные Стили для Разных Типов

```python
if article.is_news:
    # Для новостей - короткий формальный стиль
    normalized = style_normalizer.normalize_full_text(
        content,
        max_length=1500
    )
else:
    # Для статей - полный текст с нормализацией вступления
    normalized = style_normalizer.normalize_intro(content)
```
